# 逐料小结示例

每条句子单独复制到 Excel 后，也应能看出物料、两端如何变化、每台金额的方向及税口径。方括号为按当次工作簿填写的字段。

| 情形 | 可直接用于“差异小结”的句式 |
|---|---|
| 两个料号替换 | 彩盒由 1.14.001.0615（亚马逊礼盒）变更为 1.14.001.0685（中文彩盒），每台各用1个，未税成本由3.504425元降至0.867257元，减少2.637168元。 |
| 同料号调价 | 两款均使用[物料名称] [料号]，每台各用[数量及单位]，未税单价由[参考价]元变为[现价]元，每台未税成本[增加/减少][金额]元。 |
| 同料号改用量 | [物料名称] [料号] 每台用量由[旧量]变为[新量]，按[单价及计价单位]核算，每台未税成本[增加/减少][金额]元。 |
| 新增或不再列出 | 现款每台新增[数量及单位][物料名称] [料号]，未税成本增加[金额]元。／参考款每台使用[数量及单位][物料名称] [料号]，现款BOM未列，表内每台未税成本减少[金额]元。 |
| 用量分拆、合计相同 | [胶水名称] [料号] 由每台一处使用0.03克改为两处各用0.015克，折合单价一致，每台用量合计0.03克，未税成本差额为0元。 |
| 核算纠重 | 参考表同时计入[父项料号]与[子项料号]，现表按[实际计价行]计入，每台未税成本减少[金额]元，其中[金额]元来自移除重复计价。 |

整机小结另写一句：“[现成品编码] 较 [参考成品编码] 含税成本[上升/下降][金额]元/台（[幅度]%），主要来自[物料及原因]，其中[另一项]抵消[金额]元含税差额。”只有核算支持时才填入贡献金额。逐料小结使用实际双方料号；编码确实缺失时注明哪一侧缺失。
